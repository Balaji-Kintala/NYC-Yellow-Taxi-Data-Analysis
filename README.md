# NYC Yellow Taxi Trip Data Analysis

## Project Overview
This project analyzes January 2025 NYC Yellow Taxi trip data using Python to identify trip patterns, peak demand hours, passenger trends, popular pickup and drop-off zones, common routes, and data-quality issues.

## Tools and Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Data loading and understanding
2. Data quality assessment
3. Data cleaning
4. Feature engineering
5. Statistical analysis
6. Exploratory Data Analysis (EDA)
7. Data visualization
8. Business insights and conclusion

## Key Findings
- Busiest pickup hour: 6:00 PM
- Busiest day: Thursday
- Weekday trip share: 74.71%
- Median trip distance: 1.67 miles
- Median trip duration: 11.7 minutes
- Most common pickup zone ID: 161
- Most common drop-off zone ID: 236
- Most common recorded route: 237 → 236

## Project Files
- `NYC_Yellow_Taxi_Data_Analysis.ipynb` — Python analysis notebook
- `NYC YELLOW TAXI TRIP DATA ANALYSIS.docx` — project report

## Dataset
The analysis uses January 2025 NYC Yellow Taxi trip data in Parquet format.

## Conclusion
The project explores trip patterns, time-based demand, trip distances and durations, passenger data, and unusual records. Data limitations are considered when interpreting the results.
